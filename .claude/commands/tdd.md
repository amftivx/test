Remind the developer of the TDD rules for this project:

1. **Write the test first** — before any implementation code exists.
2. **Run the test** — confirm it fails (red).
3. **Write the minimum code** to make it pass (green).
4. **No line of production code without a failing test that requires it.**

If the current task involves writing or modifying code, stop and ask: "Does a failing test exist for this change?" If not, write the test first.
